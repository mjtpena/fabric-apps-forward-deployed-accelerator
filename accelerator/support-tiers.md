# Support tiers

## Tier 1: Baseline

- Rayfin-managed application data
- Generated GraphQL API and typed client
- TypeScript models
- Fabric SSO
- Static hosting
- Development and production workspaces

## Tier 2: Validated preview

- Fabric connectors
- User Data Functions
- Storage

Tier 2 features require a successful probe in the exact target tenant, region and workspace, a pinned compatible package set and documented fallback.

## Tier 3: External integration

- Existing systems without a validated connector path
- External APIs
- External compute or orchestration
- Unsupported identity requirements

Tier 3 requires an architecture decision record and cannot be presented as native baseline behaviour.
