# Lifecycle

## 0. Readiness

Validate developer tools, tenant settings, capacity, region, workspace permissions and deployment identity.

## 1. Discover

Capture users, workflow, baseline, pain, constraints, data and adoption ownership.

## 2. Assess fit

Complete the data-fit, identity-fit and capability assessments. Stop if Fabric Apps is not a good fit.

## 3. Define Minimum Viable Value

Choose the smallest production-shaped workflow that can prove a measurable improvement.

## 4. Specify and plan

Use GitHub Spec Kit for specification, planning, task decomposition, implementation and convergence. Apply this repository's constitution and Fabric-specific checks.

## 5. Implement

One bounded task per pull request where practical. Inspect before editing, run tests and collect evidence.

## 6. Review

Perform independent security, authorization, schema, accessibility, performance, capacity and operational review.

## 7. Promote

Deploy to development, validate, create a release, approve production, dry-run, deploy, smoke-test and observe.

## 8. Operate

Monitor capacity, failures, permissions, adoption and business outcomes.

## 9. Generalise

Separate customer-specific configuration from reusable patterns and feed improvements back into the accelerator.
